Я изменил код, чтобы ysf дашборд мог работать на современных серверах под линукс. Мои тесты проходили на<br>
Debian 13 (trixie),<br>
PHP 8.4.26,<br>
lighttpd 1.4.79

Больше спасибо за эту разработку [DG9VH](https://github.com/dg9vh/YSFReflector-Dashboard) и модификации от [KDØIOE](https://git.kd0ioe.com/alynch/ReflectorDashboard)!

## Описание

Файлы php (у меня) лежат в директории `/var/www/html/ysf2/`

Файл конфигурации находится в `/etc/YSFReflector2.ini`

Исполняемый файл в `/usr/local/bin/YSFReflector`

Логи пишутся в `/tmp/`

Другая особенность моей сборки, в том что все библиотеки и шрифты лежат в `/var/www/html/ysf2/assets/` мне так удобно, потому что YSF рефлектор может работать без подключения к глобальной сети.

Как работает этот дашборд вы можете посмотреть в YSF рефлекторе 25619 по адресу [RU VLGDNK](http://176.192.125.149:88/ysf2/index.php).
